# 💳 แท็บที่ 3: การเพิ่มบัตรเครดิต (Card Management Form)

## 🎯 วัตถุประสงค์
หน้าฟอร์ม (Form) สำหรับให้ผู้ใช้งานสร้าง ลงทะเบียน และจัดการหน้าบัตรเครดิตส่วนตัวของตัวเอง เพื่อนำไปเป็นตัวเลือก (Dropdown) ในการทำสเตตเมนต์ในแท็บที่ 1 และ 2ต่อไป

## 📐 โครงสร้างหน้าจอ (UI Layout Wireframe)

### 1. หัวข้อฟอร์ม (Form Header)
* **ข้อความ:** "➕ ลงทะเบียนบัตรเครดิตใบใหม่"
* **คำอธิบายย่อย:** "เพิ่มข้อมูลบัตรของคุณเพื่อนำระบบไปใช้จัดสรรยอดรูดในแต่ละเดือน"

### 2. ช่องกรอกข้อมูล (Form Input Fields Specification)

#### ฟิลด์ที่ 0: ชื่อธนาคร
* **รูปแบบฟิลด์:** select optional
* **Placeholder ตัวอย่าง:** `เช่น UOB Premier, TTB So Smart, KTC Platinum`
* **Validation:** ห้ามว่าง (Required)

#### ฟิลด์ที่ 1: ชื่อบัตร
* **รูปแบบฟิลด์:** Text Input Box
* **Placeholder ตัวอย่าง:** `เช่น UOB Premier, TTB So Smart, KTC Platinum`
* **Validation:** ห้ามว่าง (Required)

#### ฟิลด์ที่ 3: วันตัดรอบบิล (Statement Date)
* **รูปแบบฟิลด์:** Number Input Box / Dropdown เลือกวันที่
* **Placeholder ตัวอย่าง:** `เช่น ทุกวันที่ 10`
* **Validation:** ตัวเลขระบุวันที่ 1 - 31 

#### ฟิลด์ที่ 4: วันครบกำหนดชำระ (Due Date)
* **รูปแบบฟิลด์:** Number Input Box / Dropdown เลือกวันที่
* **Placeholder ตัวอย่าง:** `เช่น ทุกวันที่ 28`
* **Validation:** ตัวเลขระบุวันที่ 1 - 31

### 3. ปุ่มกดบันทึก (Submit Button)
* **UI Element:** ปุ่มขนาดเต็มความกว้าง (Full Width) สีไฮไลท์เด่นชัด
* **ข้อความบนปุ่ม:** `💾 บันทึกและลงทะเบียนบัตรเครดิต`

## ⚙️ Logic หลังบ้านที่เกี่ยวข้อง
1.  **Card Store:** เมื่อกดปุ่มบันทึก ข้อมูลบัตรนี้จะถูกนำไปต่อท้ายใน Array กลาง เช่น `[ {card_name: "UOB", limit: 100000}, ... ]`
2.  **Dynamic Update:** หลังจากบันทึกสำเร็จ บัตรใบใหม่จะต้องไปปรากฏบนหน้าสรุปในแท็บที่ 1 ทันทีโดยไม่ต้องกดรีเฟรชหน้าจอ
