# Debt Tracker — Landing Page (Handoff Context)

วางข้อความนี้ให้ Claude อีก account เพื่อทำงานต่อได้เลย

## สิ่งที่ต้องทำต่อ
แปลง landing page draft (v2) ที่เป็น HTML ให้เป็น **Next.js + shadcn/ui (Tailwind v4)** เป็นไฟล์ `app/(marketing)/page.tsx` ในโปรเจกต์ debt-tracker เดิม พร้อมแยกข้อความเป็น next-intl ตามกฎ repo

## โปรเจกต์
- **debt-tracker** — แอปคุมหนี้/รายจ่ายส่วนตัว แทน Notion tracker
- Stack: Next.js + TypeScript + Supabase + Drizzle ORM + shadcn/ui + Tailwind v4, deploy บน Vercel
- Live: https://debt-tracker-xi-eosin.vercel.app
- ภาษาไทยทั้งแอป

## เป้าหมายหน้า landing
- หน้า **ชวนเพื่อน** แสดงก่อน login (ตอนนี้แอปเปิดมาเจอ /login เลย)
- **ไม่ใช่ public marketing** — แอปใช้เอง 100% เปิดให้เฉพาะเพื่อนลอง
- ฟรี ไม่มี paid feature → **ตัด copy ขายของ/คำว่าฟรีออก** โทนเป็นมิตรแบบส่งลิงก์ให้เพื่อน
- ปุ่ม CTA: "เข้าไปลองดู" → /register, "เข้าสู่ระบบ" → /login

## Direction ที่อนุมัติแล้ว (v2)
- **Hero**: กรอบมือถือโชว์ Dashboard จริง (donut รายจ่ายตามประเภท 51/48/1, การ์ด "เงินไหลไปหมวดไหน", แถบผ่อน 1/10 งวด) + bottom nav 5 ปุ่ม
- **เล่าครบ 5 โซนของแอป**:
  1. Dashboard / ภาพรวม — กราฟรายจ่าย 6 เดือน, donut ตามประเภท, heatmap ความหนาแน่นภาระรายเดือน
  2. ค่าใช้จ่ายรายเดือน — template รายการประจำ + ดึงเข้าเดือน + ติ๊กจ่าย (ยอดรวม/จ่ายแล้ว/ค้างจ่าย) → มี checklist กดเล่นได้บน landing
  3. บัตรเครดิต — หลายบัตร, ยอดบิลเดือนนี้, รายการรูด
  4. แผนผ่อนชำระ — งวด x/y, คาดว่าจบเมื่อไหร่, เงินต้น/ดอก
  5. สมาชิก/บริการ (subscription) — ตัดเงินวันที่กำหนด, เปิด/ปิดได้
- ส่วน "ได้ลิงก์มาแล้วเริ่มยังไง" 3 ขั้น + เน้นว่าข้อมูลแต่ละคนแยกกัน (RLS เปิดอยู่)

## สี (ตาม UI จริง)
- navy (ตัวหนังสือ/ปุ่มหลัก) ~`#16243F`
- เขียว (จ่ายแล้ว / ค่าใช้จ่ายรายเดือน) `#2E9E6B`
- อำพัน (ค้างจ่าย) `#DD7A2E`
- การ์ดบัตรเครดิต ฟ้า/น้ำเงิน, หมวดหมู่: สินเชื่อ/ของขวัญ = แดง, ชำระบิล = ส้ม, บันเทิง = ม่วง
- พื้นแอป light gray (~`#F1F3F5`), ฟอนต์ IBM Plex Sans Thai + ตัวเลขเป็น IBM Plex Mono
